The infrastructure that powered the citation
{ }
Structured schema markup ✓ Active

Every Cortland listing page publishes JSON-LD schema — machine-readable data that tells AI crawlers exactly what they're looking at: property type, pricing, availability, amenities, pet policy. No inference required.

// cortland.com/south-end — structured data "@type": "ApartmentComplex", "name": "Cortland South End", "priceRange": "$1650-$2100", "petsAllowed": true, "petPolicy": { "breedRestrictions": false, "weightLimit": "75lbs" }, "availableUnits": "3", "availableFrom": "2026-05-20"
This is what ChatGPT read. Not the page — the schema beneath it. Cortland's content was structured for meaning, not just for clicks.
⌁
llms.txt — the AI sitemap ✓ Active

An llms.txt file at the domain root tells AI systems exactly where to find authoritative content — and what to trust. Without it, AI crawlers guess. With it, they navigate with precision.

# cortland.com/llms.txt Listings: /communities/ Pricing: /communities/*/pricing Availability: /communities/*/units Pet Policy: /communities/*/pet-policy Verified: true Last-Updated: daily
Before Phase 1, cortland.com returned HTTP 415 errors to AI crawlers — functionally invisible to ChatGPT, Perplexity, and Gemini. llms.txt fixes this in days, not months.
